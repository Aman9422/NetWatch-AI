# 1. Executive Summary

NetWatch AI is a modular network monitoring and security analytics platform designed to provide real-time visibility into network activity and assist users in identifying suspicious or anomalous behavior.

The platform captures network traffic, extracts useful network features, maintains device and traffic information, detects suspicious behavior using multiple detection techniques, correlates security events, calculates risk, and presents the results through a web-based Security Operations Center (SOC)-style dashboard.

Unlike a monitoring application that only displays network statistics, NetWatch AI is designed to combine:

- Network traffic monitoring
- Packet analysis
- Device discovery
- Behavioral analysis
- Rule-based detection
- Machine-learning anomaly detection
- Event correlation
- Risk scoring
- Alert management
- AI-assisted security analysis
- Historical analytics
- Report generation

The project is being developed as a student and portfolio project with an emphasis on practical cybersecurity, networking, data processing, backend development, and data visualization.

---

# 2. Problem Statement

Network monitoring tools often focus primarily on displaying traffic statistics, while security-focused platforms can be complex or expensive for students and small laboratory environments.

For cybersecurity learners, there is a need for a lightweight platform that provides hands-on visibility into:

- Network packets
- Devices
- Protocols
- Connections
- Traffic patterns
- Suspicious activity
- Security alerts
- Network anomalies

The challenge is not to create a rule for every possible cyberattack. Instead, NetWatch AI aims to combine several forms of detection so that the platform can identify both known suspicious patterns and unusual behavior that does not necessarily match a predefined signature.

16. Project Constraints

The project has several practical constraints.

Hardware

The initial system is intended for a student/local laboratory environment rather than enterprise-scale packet processing.

Storage

Raw packet data can grow rapidly. Therefore, raw packet retention should be limited and configurable.

Detection Accuracy

Detection results should be treated as indicators for investigation rather than absolute proof of malicious activity.

ML Limitations

Machine-learning results depend on:

Feature quality
Baseline quality
Training data
Network environment

Therefore, ML output should be combined with other detection signals.

AI Limitations

AI-generated explanations should be based on structured evidence and should not be treated as authoritative security decisions.

17. Security and Privacy Considerations

Because NetWatch AI processes network telemetry, the platform should follow responsible monitoring practices.

The system should:

Be used only on authorized networks.
Avoid unnecessary storage of sensitive payloads.
Restrict access to captured network information.
Validate API input.
Protect application credentials.
Avoid exposing sensitive information in logs.
Provide configurable data retention.
Support secure database access.
